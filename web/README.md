# Casa Caribe - Web Application

This is the Next.js web application for Casa Caribe.

## Getting Started

First, install dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Building

To create a production build:

```bash
npm run build
npm start
```

## Deployment

This application is configured to deploy to Vercel. Push changes to the main branch to trigger automatic deployment to [casacaribe.vercel.app](https://casacaribe.vercel.app).
